## 🚀 Project Overview
This project provides an **interactive analytical dashboard** for exploring Walmart sales performance using **Streamlit**.  
It includes:

- 📈 Descriptive Analytics  
- 🎛 Interactive Filters  
- 🧠 Automated Business Insights  
- 🧩 Downloadable Processed Data  
- 🖥 Cloud + Local Run Support  

This dashboard allows analysts, stakeholders, and data teams to **understand sales behavior, profitability, product performance, customer trends, and operational inefficiencies** with dynamic filtering.
